# Career-Roadmap-Generator
A lightweight and user-friendly career roadmap generator that helps users select job roles, track learning progress, and download personalized roadmaps as PDFs. Designed with a focus on scalability and top-tier user experience.

This project is a dynamic web-based application that enables users to generate, track, and download customized career learning roadmaps based on their selected job roles and experience levels.

🌟 Features
🔐 User-friendly login page

📊 Interactive dashboard for job role and level selection

🗺️ Personalized roadmap cards including:

Learning topics

YouTube/resource links

Completion checkboxes

📈 Real-time progress tracking

📄 "Download PDF" option to save roadmap offline

⚡ Built to be lightweight, scalable, and focused on user experience

🛠️ Tech Stack
Frontend: HTML, CSS, JS
Backend: Java-Script
Api: Gemini 
Styling: CSS
